## 🧠 Sobre mim

Construo sistemas financeiros de alta criticidade.

Atuo na arquitetura de plataformas de crédito digital, automação de core financeiro e integrações em larga escala.  
Sistemas sob minha responsabilidade já processaram **dezenas de milhares de propostas por dia**, com foco em previsibilidade, automação e escalabilidade.

Hoje meu foco está em:

- JavaScript moderno com **Node.js e React**
- APIs robustas e bem versionadas
- Arquitetura **SaaS multi-tenant**
- Automação de fluxos financeiros
- Integrações com bancos, gateways e concessionárias
